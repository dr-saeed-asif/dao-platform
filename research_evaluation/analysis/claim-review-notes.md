# First-repeat claim review

This is a qualitative, unblinded source inspection by the research assistant that ran the experiments, not an independent human annotation. Scope was all four first-repeat final answers in the small-model full condition. Match each row in `first-pass-claim-review.csv` to the raw record by regime, mode, repeat, and case. Repeated totals expressed as a separate sum assertion were counted separately. Reproduced question headings and fallback status notices were excluded. A claim is supported when the cited/returned excerpt states it or supports direct arithmetic. Explicit references count only IDs attached to that assertion. The vote-detail denial is contradicted because the same JSON contains the option-index breakdown. Terminal punctuation around a title was ignored. Independent blinded annotation is still required for manuscript-level estimates.
